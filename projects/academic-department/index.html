PROJECT NOTE

A Website for the Academic Community

The website for the Academic Department of the PKU School of Mathematical Sciences Student Union.

A website for sharing mathematical problems, course resources, and academic activities within the School of Mathematical Sciences community.

Visit the website · Source code

What it supports

The site brings together problem sets and solutions, course resources, mock-exam materials, and activity records. Markdown and KaTeX support mathematical content.

Keeping it maintainable

Built with React, TypeScript, Vite, and Tailwind CSS. Content is separated from page components: maintainers update configuration files to add resources, activities, or new problems. Shared components keep the navigation and presentation consistent across pages.

Project context

A campus software project for the SMS Student Union Academic Department. The linked repository documents the implementation and contribution workflow; no usage or impact figures are claimed here.
